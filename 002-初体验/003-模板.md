`Vue`通过 `template` 和 `JSX` 来指定需要渲染的UI结构，其中 `template`使用较多

1. 如果有`render`直接调用`render`方法，获取返回的结果值

2. 查看 `template` 值

   + 以`#`开头，将其作为css选择器，找到对应DOM，以其 `innerHTML`作为渲染值

   + 不是`#`开头，自动以`template`属性值，作为需要渲染的模板字符串

 3. 没有 `template`
    + 直接使用挂载点的 `innerHTML` 作为需要渲染的模板



```js
// 情况1: 使用render函数（最高优先级）
createApp({
  data() {
    return { message: 'Hello from render!' }
  },
  render() {
    // 使用h函数创建虚拟DOM
    return h('div', { class: 'greeting' }, this.message)
  }
}).mount('#app')

// 情况2: 使用CSS选择器
createApp({
  template: '#app-template'  // 查找 id="app-template" 的元素
}).mount('#app')

// 情况3: 直接模板字符串  
createApp({
  template: `<div>{{ message }}</div>`  // 直接使用字符串
}).mount('#app')

// 情况4: 无template选项
createApp({
  data() { return { message: 'Hello' } }
  // 没有template，使用挂载点的innerHTML
}).mount('#app')
```

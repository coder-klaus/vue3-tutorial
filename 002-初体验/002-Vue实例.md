## 应用实例

主要对当前应用进行全局配置 「 `config`、`directive`等 」 和 功能扩展「 `use` 」

```js
const 应用实例 = {
  component(name, component) {
    // 组件注册逻辑
  },
  config: {  // 属性，用于对应用实例进行去全局配置
    errorHandler(err, instance, info) { }, // 全局错误处理函数
    globalProperties: {
      // 自定义需要全局挂载的属性或方法
    },
		// ....
  },
  version: 3.5.18,  // 版本信息属性
  mixin(mixinObject) {
    // 混入逻辑
  },
  directive(name, definition) {
    // 指令注册逻辑
  },
  provide(key, value) {
    // 依赖注入逻辑
  },
  use(plugin) {
    // 插件使用逻辑
  },
  mount(rootContainer) {
    // 挂载应用到DOM
  },
  // .....
}
```



## 组件实例

无论是 Vue2 还是 Vue3 ，组件经过编译后都是标准组件配置对象

这个配置对象会传递给Vue用于创建组件实例的工厂函数，并生成组件实例

组件实例存在`render`方法，该方法会返回VDOM，并最终生成DOM



组件每调用一次 「 `<Component />` 都会创建一个新的组件实例

组件实例和组件实例之间是相互独立，互不干扰的

所以组件可以被多次调用且他们之间是互相独立且互不干扰的

```js
const 组件实例 = {
  $data: (...),         // 响应式数据对象
  $el: (...),           // 根 DOM 元素
  $emit: (...),         // 事件触发方法
  $forceUpdate: (...),  // 强制组件重新渲染
  $nextTick: (...),     // 下一个 DOM 更新周期回调
  $options: (...),      // 组件的选项对象
  $parent: (...),       // 父组件实例
  $props: (...),        // props 对象
  $refs: (...),         // ref 引用对象
  $root: (...),         // 根 Vue 实例
  $slots: (...)         // 插槽对象
  // .....
}
```

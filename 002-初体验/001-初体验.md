## 挂载点

1. 一个 DOM元素
   + Vue 一般为 div#app
   + React 一般为 div#root
2. 渲染后内容会作为 挂载点的 innerHTML 被插入
   + 挂载点中原本内容会被渲染后的内容替换
3. 挂载点又叫挂载容器
   + 挂载点本身不是应用的一部分
   + 挂载点中的内容才是



## createApp

### 基本使用

```js
const 应用实例 = Vue.createApp(组件配置对象 | SFC组件 )
```

`createApp` 会将参数转换为标准组件配置对象，所以其可以接收的值为

+  直接传入包含template、data、methods等属性的配置对象
+ 导入的SFC组件
  + SFC（Single File Component）经过构建工具编译后会成了标准组件配置对象，可以直接使用



### 使用示例

```js
const app = Vue.createApp({
  template: `<div>Hello Vue</div>`
})
```



## mount

### 基本使用

```js
const 根组件实例 =  应用实例.mount(css选择器字符串 | 挂载点对应的DOM元素)
```

应用实例的绝大多数方法在被调用后返回的都是应用实例本身，所以可以链式调用

```js
Vue.createApp().use().mount()
```

但 mount 方法 返回的不是应用实例，而是根组件对应的根组件实例

2. 渲染后的内容，作为 挂载点的 `innerHTML`进行设置，整体替换挂载点中原本存在的内容



### 使用示例

```js
app.mount('#app')
```

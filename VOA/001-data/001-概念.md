1. data 必须是"返回状态对象的工厂函数"，从而避免跨组件状态污染
    + 即多个组件共用同一个组件状态对象，从而引发冲突
2. data 会在组件初始化时被统一处理

    - Vue2：通过 Object.defineProperty 依次对每一个状态进行数据劫持
      
    - Vue3：直接基于 props、data、computed 这类需要暴露的属性生成一个对象，对这个对象进行 Proxy 代理劫持
    
3. 像 props、data、computed、methods，以及 setup 返回的值都在组件实例初始化时，被暴露给组件实例（Vue2）或生成代理对象（Vue3）

    - 可以直接在模板中直接使用它们
      
    - 某些 option 方法中 this 默认指向组件实例（Vue2）或代理对象（Vue3），此时可以直接通过 this 访问它们
      

```js
data() {
  return {
    message: 'Hello Vue'
  }
}
```

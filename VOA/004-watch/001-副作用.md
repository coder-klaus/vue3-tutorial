一个函数满足如下条件

1. 确定的输入一定存在确定的输出
2. 不依赖，也不修改 外部状态或外部环境

那么这个函数 就是 纯函数，而所有破坏纯函数 纯度的操作都可以被认为是 副作用 「 side effect 」

例如:

1. I/O 操作 「 操作了外部环境 」
2. 修改了状态
3. 依赖于全局变量
4. 。。。

并非所有函数都必须是纯函数，因为纯函数能实现的功能有限，为了实现功能，很多时候我们必须使用非纯函数

但纯函数有几个非常显著的特点

1. 确定的输入一定有确定的输出
   + 只要知道参数，我们就可以依赖函数的执行结果
2. 函数是独立的，耦合度极低的
   + 对于构建工具而言，一个纯函数如果没有被使用，则可以直接 tree-shaking，而不会产生任何影响



组件最终会被编译为 接收 props 并返回需要渲染的 VDOM 的 render 函数，所有破坏这个 render 函数纯度的行为，就叫做组件副作用行为

这些副作用行为包括但不限于

1. 操作DOM
2. 发生网络请求
3. 日志打印
4. 。。。

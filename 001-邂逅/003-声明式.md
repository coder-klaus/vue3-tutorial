## 声明式框架

按照框架预设规则描述好界面和业务逻辑

后续只要关心业务逻辑即可，根据实际逻辑修改数据，当数据改变界面自动更新



传统前端开发是 业务逻辑 + 界面渲染和更新

声明式框架的功能是 我们将界面渲染和更新「 DOM操作 」外包给了框架来执行

我们只需要关心业务逻辑



### 状态

参与界面渲染并在值发生改变时界面需要发生更新的数据

一般情况下我们会使用特定 api 来更新状态，以便于在值发生改变时界面自动更新

而如果对状态进行了劫持，可以自动监听状态变更并自动更新界面，则这个状态也叫响应式数据或响应式状态





### 框架

库 是 一系列方法的集合，我们可以只使用其中的某一个方法

框架 是一套完整的解决方案，有自己的编程范式「 编程思想、设计思想 」和语法规则，具有一定的侵入性，我们需要按照其预设语法规则进行使用



## 命令式编程

像 原生 JavaScript 或 jQuery 形式进行开发，我们即需要关心 业务逻辑，又要操作DOM实现界面渲染和更新的编程方式叫命令式编程

其关心 **怎么做 「 how to do 」**

我们即需要优化和完成业务逻辑，还需要实现和优化界面渲染和重构，以减少页面的重绘和重排



声明式编程 就是将 DOM操作外包给了框架来实现，即界面渲染和更新交给了框架来完成，我们只需要告诉框架我们需要完成什么功能即可

其更关心 **做什么 「 what to do 」**

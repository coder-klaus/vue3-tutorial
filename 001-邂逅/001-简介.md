1. Vue  也叫 Vue.js
2. 用于构建现代用户界面的前端框架
3. 特点
   + 组件化
   + 声明式
   + 渐进式



### 用户界面

**用户界面**（User Interface，UI）是人与计算机交互的操作界面, 用于向计算机发出对应指令

用户界面包括但不限于图形用户界面（GUI）、命令行界面（CLI）等

其中GUI 又可以被分为 应用程序界面、网页界面等

在前端开发领域，UI 特指**网页界面**



## 简介

### 🎯 基本概念
**Vue**（也可写作 `Vue.js`）是一个用于构建现代用户界面的渐进式 JavaScript 前端框架。



### ✨ 核心特点

- **🧩 组件化**：将界面拆分为可复用的独立组件
- **📝 声明式**：通过模板语法描述界面应该呈现的状态
- **🔄 渐进式**：可以逐步引入，与现有项目无缝集成



### 💡 用户界面（UI）

**用户界面**（User Interface，UI）是人与计算机交互的操作界面，是用户向计算机发出指令的媒介。

#### 🖥️ UI 的主要类型
- **图形用户界面**（GUI）
  - 应用程序界面
  - 网页界面
- **命令行界面**（CLI）
- 其他交互界面

#### 🌐 前端开发中的 UI
在前端开发领域，UI 特指**网页界面**，包括网站和 Web 应用的视觉呈现和交互体验。

---

*Vue.js 正是为了让开发者更高效地构建这些现代化的网页用户界面而诞生的框架。*
